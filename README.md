# Aligned DNA Clustering

本地相似性分析工具：把一批**已经对齐**的 DNA 序列转换为可复核的成对
距离矩阵、逐对比较表和 UPGMA 层次聚类树。仅使用 Python 3.12 标准库，
不访问网络，不依赖第三方计算库。

本工具不做序列比对，也不推断真实进化关系，只对给定的对齐结果做距离
与聚类计算。

## 使用方法

```sh
python -m alignment_cluster path/to/input.fasta -o path/to/output_dir
```

输出目录不存在时会自动创建，运行成功后生成三个文件：

- `distance_matrix.csv`：对称距离矩阵，对角线为 0，行列均按标识字典序。
- `pairwise_comparisons.csv`：每个无序序列对一行，按两个标识排序。
- `tree.json`：按发生顺序记录的合并事件、叶节点信息与最终聚类树。

## FASTA 输入规则

- 至少包含两条等长、非空序列；长度按对齐后的位点（列）计算。
- 标题行以 `>` 开始，其后第一个非空白词作为标识，必须非空且全文件唯一；
  其余文字作为描述保留到 `tree.json`。
- 序列允许跨多行，文件中允许空白行；序列行内空白被忽略，字母统一转为大写。
- 只接受 `A`、`C`、`G`、`T`、`N` 与连字符 `-`，其它字符直接拒绝。
- 以下情况均报错并以非零状态退出：标题前出现序列、重复标识、长度不一致、
  非法字符、空序列或少于两条序列。

## 距离口径（缺失位点的影响）

对每一对序列，**仅**统计该位置上双方碱基都属于 `A/C/G/T` 的位点；任意
一方为 `N` 或 `-` 时，该位点只从**当前序列对**中排除，不影响其它序列对
对同一列的使用。因此不会从整份比对中删除任何列。

- `comparable_sites`：可比较位点数（双方均为 ACGT）。
- `differing_sites`：可比较位点中双方碱基不同的数量。
- `distance = differing_sites / comparable_sites`。

若任一不同序列对的可比较位点数为 0，整次分析失败，错误信息会指出对应
的两个标识，且不生成或覆盖任何报告文件。

相同序列允许距离为 0；零距离合并不会删除任何样本记录，全部叶节点始终
保留在树中。

## UPGMA 聚类规则

- 初始时每条序列为一个单元素簇。
- 每轮合并当前簇间距离最小的两个簇。
- 簇间距离是跨两簇**所有原始序列对**距离的算术平均
  （`|A| × |B|` 个距离等权），因此大小不同的簇不会被等权处理。
- 距离相同出现并列时，比较两个候选簇各自最小标识组成的有序对，取字典序
  最小者；每个合并节点的两个子树也按各自最小标识排列。
- 叶节点高度为 0；合并节点高度为**本次簇间距离的一半**；分支长度等于
  父子高度之差（即 `parent.height - child.height`）。
- 选择合并时直接使用未舍入的距离；CSV/JSON 中写出的数字用最短的精确
  表示（`repr`），便于复核。

## tree.json 结构

- `leaf_order`：叶标识字典序；`leaves` 给出描述与高度 0。
- `merges`：按发生顺序排列的合并记录，含 `order`、合并节点 `id`、
  `child_ids`、成员标识、未舍入的 `inter_cluster_distance` 与 `height`。
  仅凭 `merges` 即可从叶节点逐步还原每次合并及成员，不依赖输入文件中
  记录的原始顺序。
- `tree`：最终嵌套树；每个节点含 `id`、`type`（`leaf`/`merged`）、
  `height`、`branch_length` 与全部成员 `members`，合并节点还含
  `children`。

## 示例

`examples/example.fasta` 展示跨行、`N`、间隙和零距离；预生成结果见
`examples/output/`。可用以下命令重新生成：

```sh
python -m alignment_cluster examples/example.fasta -o examples/output
```

## 测试

```sh
python -m unittest discover -s tests
```

测试覆盖：缺失位点（N 与间隙的成对排除）、零距离合并、距离并列时的字典序
选择、大小不等簇的平均距离、输入记录换序后结果一致，以及非法输入非零退出
且不写出报告。
